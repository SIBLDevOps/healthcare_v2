1. ARCHITECTURAL OVERVIEW & DESIGN SYSTEM
================================================================================
BeyondSure provides an integrated, patient-first preventive healthcare web
ecosystem. The architecture is engineered using high-performance Vanilla
JavaScript (ES6+ modular IIFE patterns), Bootstrap 5.3.3, and custom CSS
(assets/css/style.css).

Key Design Language & CSS Namespaces:
- .bys-*  : Core brand elements (Header, Topbar, Footer, Buttons, Marquees)
- .fd-*   : Doctor discovery & directory styling
- .dp-*   : Doctor profile & single-doctor scheduling
- .sp-*   : Wellness store cards & listing
- .pd-*   : Product details, gallery & tabs
- .ct-*   : Shopping cart & GST financial calculations
- .sv-*   : Universal service vertical styling (cards, steppers, date strips,
            time slots, tracking timelines, digital QR cards)

2. SERVICE 1: DIAGNOSTIC LAB TESTS & HEALTH PACKAGES (lab-tests/)
================================================================================
Industry References: Tata 1mg, Apollo 24/7, Dr Lal Pathlabs, MediBhai

DIRECTORY STRUCTURE:
lab-tests/
├── index.html            --> Package discovery, health concern filters & pincode validator
├── book.html             --> 3-step home collection scheduling wizard
└── confirmation.html     --> Real-time order ID, tracking timeline & phlebotomist badge

DETAILED FLOW & USER JOURNEY:
Step 1: Explore & Filter (index.html)
- Users browse popular health checkup packages (e.g., Comprehensive Full Body
  Checkup 64 tests, Senior Citizen Profile 78 tests, Diabetes & Heart Profile,
  Vitamin D3/B12 Duo, Thyroid Total).
- Users can filter packages by Health Concern (Full Body, Diabetes, Vitamins,
  Thyroid, Women's Care) or search tests in real-time.
- Instant Pincode Checker: Users enter their 6-digit Indian pincode to confirm
  doorstep sample pickup serviceability.
- Add to Cart: Users click "Book Test" which updates the sticky bottom cart bar.

Step 2: Scheduling & Patient Info (book.html)
- Step 2.1: Patient Details (Full Name, Age, Gender, WhatsApp Mobile, Email).
- Step 2.2: Home Address (Pincode, City, Flat/Street, Landmark) and Date strip
  picker (next 7 days).
- Step 2.3: Slot Selection (Morning fasting slots 6:30 AM – 10:30 AM vs evening
  non-fasting slots) and Payment Mode selection (Pay at Collection vs Prepay).
- Stepper validation ensures zero invalid submissions.

Step 3: Confirmation & Tracking (confirmation.html)
- Generates unique Booking ID (e.g. LAB-892104).
- Phlebotomist Card: Displays assigned certified collector (Suresh Kumar),
  safety certifications, and daily temperature clearance (98.4°F).
- Doorstep Check-in QR: Procedural SVG QR code for authentication at doorstep.
- Live 5-stage tracking timeline (Booked -> Collector Assigned -> Sample Picked
  Up -> NABL Processing -> Digital Report Ready).
- Pre-test fasting preparation checklist.

3. SERVICE 2: ONLINE PHARMACY & MEDICINE DELIVERY (medicines/)
================================================================================
Industry References: PharmEasy, Tata 1mg, Apollo 24/7

DIRECTORY STRUCTURE:
medicines/
├── index.html            --> Prescription upload dropzone, medicine catalog & search
├── checkout.html         --> Prescription review, delivery address & speed selector
└── confirmation.html     --> Order tracking, pharmacist license badge & ETA

DETAILED FLOW & USER JOURNEY:
Step 1: Browse & Upload Prescription (index.html)
- Order With Prescription Box: Drag-and-drop or file upload for JPG, PNG, or PDF
  doctor prescriptions. Prescriptions are cached in browser localStorage.
- Search by brand or active salt name (e.g. Metformin, Telmisartan, Pantoprazole,
  Dolo 650, Limcee Vitamin C, Shelcal Calcium, Livnora Syrup).
- Categorized chips filter: Diabetes, Cardiac, Digestive, Pain Relief, Vitamins,
  and Ayurvedic.
- Items feature clear Rx-Required vs. OTC badges and manufacturer details.
- Add to Basket updates the sticky checkout bar.

Step 2: Prescription Verification & Checkout (checkout.html)
- Step 2.1: Review attached prescription file and enter recipient contact.
- Step 2.2: Delivery Address with 6-digit pincode validation.
- Step 2.3: Delivery Speed Selection:
  * Standard Delivery (24–48 Hours) -> FREE
  * Express 2-Hour Delivery (Available in metros) -> +₹49
- Payment Options: Cash on Delivery (COD) vs Online Prepaid (UPI/Cards).

Step 3: Order Confirmation & Live Tracking (confirmation.html)
- Displays Order ID (e.g. MED-718290) and estimated delivery date/time.
- Dispensing Pharmacist Badge: Displays the reviewing pharmacist's name,
  credentials, and state license number (e.g. Dr. Arvind Kulkarni, MH-PH-89120B).
- Delivery Verification QR: Tamper-proof security QR code for delivery rider.
- Tracking Timeline: Received -> Pharmacist Verified -> Packed -> Out for Delivery
  -> Delivered.
- Medicine storage and safety guidelines.

6. CROSS-SERVICE SHARED INFRASTRUCTURE (services-core.js)
================================================================================
The entire service suite is powered by the unified utility engine:
assets/js/services-core.js (window.BS_SVC).

Core Modules:
- BS_SVC.makeCart(key): Isolated client-side carts for each vertical:
  * bs_lab_cart
  * bs_med_cart
- BS_SVC.orders: Persistent booking repository in localStorage ('bs_svc_orders'):
  * orders.save(service, data) -> returns prefixed ID (e.g. LAB..., MED..., DEN...)
  * orders.get(id)
  * orders.update(id, patch)
  * orders.list(service)
- BS_SVC.valid & checkFields(container): Client-side input validation
  (Indian mobile, 6-digit pincode, age, email, required text).
- BS_SVC.dateStrip(n, offset, selectedIdx): Generates interactive horizontal
  date buttons with day names, dates, and months.
- BS_SVC.slotButtons(slots, selected): Renders accessible time slot buttons.
- BS_SVC.stepper(root, options): Manages multi-step wizard navigation, step
  indicator pills, and step validation gates.
- BS_SVC.timeline(steps, doneIndex): Renders responsive progress tracking
  timelines with checkmark dots.
- BS_SVC.qrSvg(seed, size): Generates procedural, scalable inline SVG QR codes
  derived deterministically from order and pass IDs.
- BS_SVC.toast(msg): Non-blocking floating toast notifications.
- BS_SVC.initSite(): Binds sticky headers, mobile offcanvas menus, back-to-top
  buttons, marquee tickers, and AOS animations.
